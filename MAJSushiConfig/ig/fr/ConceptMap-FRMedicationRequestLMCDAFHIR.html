ConceptMap: Mapping FRLMPrescriptionItem → FRCDATraitementPrescrit / FRLMPrescriptionItem → FRMedicationRequestDocument

URL officielle: https://interop.esante.gouv.fr/ig/metier/document-core/ConceptMap/FRMedicationRequestLMCDAFHIR Version: 0.1.0
Draft à partir de 2026-09-07 Nom computable: FRMedicationRequestLMCDAFHIR

Mapping des éléments du modèle métier FRLMPrescriptionItem vers l'entrée CDA FRCDATraitementPrescrit, puis vers le profil FHIR FRMedicationRequestDocument.

Langue : fr

This mapping does not specify any particular context of use.

Code sourcerelationCode cibleCommentaire
FRLMDosageInstructions.renderedDosageInstructionis equivalent toSubstanceAdministration.text (Partie narrative de l’entrée)
FRLMDosageInstructions.dosageDetails.sequence(not mapped)
FRLMDosageInstructions.dosageDetails.noteis equivalent toSubstanceAdministration.entryRelationship:frInstructionsAuPatient (Entrée Instructions au patient)
FRLMDosageInstructions.dosageDetails.doseAndRate.dose[x]is equivalent toSubstanceAdministration.doseQuantity (Dose à administrer : S'il n'y a pas de traitement, utiliser une valeur nullFlavor. S'il y a un traitement, les sous-éléments 'low' et 'high' permettent de fournir les doses minimales et maximales à administrer. Dans le cas où la dose est fixe, ces deux sous-éléments prendront les mêmes valeurs. Dans chaque élément 'low' et 'high', un élément 'translation' peut permettre de pointer sur l'élément de la partie narrative relative à cette information. Dans le cas où l'on s'exprime en quantités indénombrables, l'unité doit être transmise. Les unités sont exprimées selon le système de codage UCUM. Dans le cas où l'on s'exprime en quantités dénombrables (capsules, comprimés, gélules, etc.) l'unité ne doit pas être renseignée. A la place, on ajoute un champ 'translation' qui permet de pointer sur l'élément de la partie narrative relative à cette information.)
FRLMDosageInstructions.dosageDetails.doseAndRate.rate[x]is equivalent toSubstanceAdministration.rateQuantity (Rythme d'administration : Le rythme d'administration permet d'indiquer la quantité de produit à administrer par unité de temps. Les sous-éléments 'low' et 'high' permettent de fournir le rythme minimal et maximal de l'administration. Dans le cas où le rythme est fixe, ces deux sous-éléments prendront les mêmes valeurs. L'argument @value permet d'indiquer la quantité de produit à administrer. L'argument @unit permet d'indiquer le rythme d'administration en combinant l'unité de quantité et l'unité de temps (séparés par le caractère ‘/'). Les unités sont exprimées selon le système de codage UCUM. Dans chaque élément 'low' et 'high', un élément 'translation' peut permettre de pointer sur l'élément de la partie narrative relative à cette information.)
FRLMDosageInstructions.dosageDetails.frequencyis equivalent toSubstanceAdministration.effectiveTime:effectiveTimeFrequence (Fréquence d'administration)
FRLMDosageInstructions.dosageDetails.frequency.numberOfTimesmaps to wider conceptSubstanceAdministration.effectiveTime:effectiveTimeFrequence (Fréquence d'administration)Ce profil CDA n'expose pas les sous-éléments de la fréquence séparément ; ils sont portés globalement par effectiveTime:effectiveTimeFrequence (structure PIVL-TS/EIVL-TS/SXPR-TS).
FRLMDosageInstructions.dosageDetails.frequency.periodmaps to wider conceptSubstanceAdministration.effectiveTime:effectiveTimeFrequence (Fréquence d'administration)Ce profil CDA n'expose pas les sous-éléments de la fréquence séparément ; ils sont portés globalement par effectiveTime:effectiveTimeFrequence (structure PIVL-TS/EIVL-TS/SXPR-TS).
FRLMDosageInstructions.dosageDetails.frequency.dayOfWeekmaps to wider conceptSubstanceAdministration.effectiveTime:effectiveTimeFrequence (Fréquence d'administration)Ce profil CDA n'expose pas les sous-éléments de la fréquence séparément ; ils sont portés globalement par effectiveTime:effectiveTimeFrequence (structure PIVL-TS/EIVL-TS/SXPR-TS).
FRLMDosageInstructions.dosageDetails.frequency.timeOfDaymaps to wider conceptSubstanceAdministration.effectiveTime:effectiveTimeFrequence (Fréquence d'administration)Ce profil CDA n'expose pas les sous-éléments de la fréquence séparément ; ils sont portés globalement par effectiveTime:effectiveTimeFrequence (structure PIVL-TS/EIVL-TS/SXPR-TS).
FRLMDosageInstructions.dosageDetails.frequency.additionalInstructionsis equivalent toSubstanceAdministration.entryRelationship:frInstructionsAuPatient (Entrée Instructions au patient)
FRLMDosageInstructions.dosageDetails.dateOfAdministration(not mapped)Pas d'élément CDA dédié à une liste de dates précises de prise dans ce profil.
FRLMDosageInstructions.dosageDetails.conditionOfAdministrationis equivalent toSubstanceAdministration.precondition (Précondition à l'utilisation du médicament : Permet de décrire les conditions préalables à l'utilisation du médicament. L'attribut @value de l'élément 'reference' est une URI qui pointe vers la partie narrative du document CDA décrivant ces conditions préalables.)
FRLMDosageInstructions.dosageDetails.date[x]maps to wider conceptSubstanceAdministration.effectiveTime:effectiveTimeDuree (Durée de traitement)effectiveTime:effectiveTimeDuree porte la durée de traitement globale (IVL-TS) ; le modèle métier permet en plus une durée ou un intervalle de durée non distingués séparément côté CDA.
FRLMDosageInstructions.dosageDetails.duration(not mapped)Pas d'élément CDA dédié à une durée d'administration ponctuelle (ex. perfusion) dans ce profil.
FRLMDosageInstructions.dosageDetails.eventTimemaps to wider conceptSubstanceAdministration.entryRelationship:frInstructionsAuPatient (Entrée Instructions au patient)Pas d'élément CDA structuré pour un événement déclencheur ; porté par le texte libre des instructions au patient.
FRLMDosageInstructions.dosageDetails.eventEndSequence(not mapped)
FRLMDosageInstructions.dosageDetails.bodySiteis equivalent toSubstanceAdministration.approachSiteCode (région anatomique d'administration : Dans le cas où la posologie n'est pas structurée et décrite uniquement dans la partie narrative, cet élément ne doit pas être présent. Dans le cas où la posologie est structurée, si la région anatomique d'administration est connue, elle peut être indiquée.)
FRLMDosageInstructions.dosageDetails.routeOfAdministrationis equivalent toSubstanceAdministration.routeCode (Voie d'administration : Dans le cas où la posologie n'est pas structurée et décrite uniquement dans la partie narrative, cet élément ne doit pas être présent. Dans le cas où la posologie est structurée, si la voie d'administration est connue, elle peut être indiquée à partir de la terminologie EDQM (0.4.0.127.0.16.1.1.2.1). Si elle n'est pas connue, la raison pour laquelle elle est inconnue peut être décrite en utilisant l'attribut nullFlavor.)
FRLMDosageInstructions.dosageDetails.maxDosePerPeriod.quantityis equivalent toSubstanceAdministration.maxDoseQuantity.numerator (Numerator)
FRLMDosageInstructions.dosageDetails.maxDosePerPeriod.durationis equivalent toSubstanceAdministration.maxDoseQuantity.denominator (Denominator)
FRLMDosageInstructions.dosageDetails.maxDosePerAdministration(not mapped)Pas d'élément CDA distinct pour une dose maximale par administration ; maxDoseQuantity est déjà utilisé pour la dose maximale par période.
FRLMDosageInstructions.dosageDetails.maxLifetimeDose(not mapped)Pas d'élément CDA distinct pour une dose maximale sur la durée de vie ; maxDoseQuantity est déjà utilisé pour la dose maximale par période.
