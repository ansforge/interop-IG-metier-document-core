Modèle logique: Logical model - FR LM Participant

URL officielle: https://interop.esante.gouv.fr/ig/document-core/StructureDefinition/FRLMParticipant Version: 0.1.0
Draft à partir de 2026-08-20 Nom computable: FRLMParticipant

Personne/Structure impliquée dans les évènements décrits par le document qui n'a pas été mentionné ailleurs.

Utilisations:

  • Utilise ce/t/te Modèle logique: Logical model - FR LM Encounter and Logical model - FR LM Header Document
