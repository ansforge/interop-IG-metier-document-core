Modèle logique: Logical model - FR LM Corps document

URL officielle: https://interop.esante.gouv.fr/ig/document-core/StructureDefinition/FRLMCorpsDocument Version: 0.1.0
Draft à partir de 2026-08-24 Nom computable: FRLMCorpsDocument

Eléments métier du corps d'un document contenant les sections du document.

Utilisations:

  • Ce Modèle logique n'est utilisé par aucun autre profil dans ce guide d'implémentation

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
